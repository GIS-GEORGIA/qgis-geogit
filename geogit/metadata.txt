about=Puts the project folder (project file, vector and raster layers, styles, documents) under git with Git LFS for large geodata and drives it from a QGIS panel: changed files, versions, branches, publish/get updates with GitHub, Forgejo or any git server, and a history graph coloured by author with filters. Double-click a file to compare versions: vector layers show added, modified and deleted features on the map; rasters get a difference layer, outlines of changed areas and a swipe tool; project files list changed layers, styles, layer tree and layouts. Merges combine GeoPackage edits feature by feature and attribute by attribute, with a window for the conflicts that remain. Git LFS file locks show who is editing what. Needs git (and git-lfs for large files and locks). License: GPL-3.0-or-later.

changelog=0.7.3 - Field types always use QMetaType (clean under the Qt6 compatibility scan); first release on plugins.qgis.ge.
    0.7.2 - Tested on QGIS 3.44 (Qt5), 4.0 and 4.2 (Qt6): QAction import, menu actions, enum use and layer-tree checks made Qt6-safe (on QGIS 4.0 the old raster version stayed visible). Minimum QGIS is now 3.44.
    0.7.1 - Git LFS fixes found on a real server: clones fetch real file content instead of pointer files, repositories cloned without LFS get it switched on, pushing a file someone else locked is now refused (lfs.locksverify), lock output of git-lfs 3.3 is read.
    0.7.0 - History tools: tag a version (sent with Publish), HTML change report per version (features, pixels, project items per file), restore a file from an old version, undo a version (revert), add an old version of a layer to the map. Local Forgejo server setup in server/, packaging script.
    0.6.0 - Merge and conflicts: merge a branch, get updates with conflicts, conflict window (keep mine / take theirs, shapefiles as one), GeoPackage merged feature by feature and attribute by attribute with a table for the features both sides changed, both sides on the map, finish or abort the merge.
    0.5.0 - Project file changes: layers added, removed, renamed, new source, style, labels, form, CRS; layer tree visibility, groups and order; project CRS; print layouts. File locks with Git LFS: lock, unlock, force unlock, Locks tab, lock marks in the changes list, warning before saving a file someone else locked.
    0.4.0 - Raster changes on the map: difference layer (blue lower, red higher; change size for imagery), outlines of changed areas, pixel statistics, metadata changes, swipe tool to slide between versions. Large rasters are compared block by block; other grids are warped onto the old one. Versions are cached inside .git.
    0.3.0 - Vector changes on the map: double-click or right-click a vector file to see added, modified (with the old shape) and deleted features as a styled layer, for any saved version or for unsaved edits. Works with GeoPackage, shapefile, GeoJSON and other OGR formats.
    0.2.0 - History graph with branches and merges, colour per author, filters by author, file type and text, history of a single file (right-click a file).
    0.1.0 - First version: project-folder repository with Git LFS, changes list, save version, publish/get updates, branches, history list with authors.
